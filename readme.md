# 万步网人类行为模拟器 (Wanbu Auto-Sync)

这是一个基于 Python 的万步网计步器数据自动化同步与人类行为模拟工具。

## 功能特色
* **协议拦截**：通过 `mitmproxy` 自动拦截并阻断原始 0 步数据。
* **行为建模**：动态随机分配步数，精准控制步频 (110-140) 以符合处方要求。
* **物理模拟**：区分“任务时段”与“日常时段”，动态计算有效步数与步行时间。
* **状态记忆**：本地存储同步进度，支持多日数据批量合并上传。

## 使用环境
* Python 3.8+
* `requests`, `mitmproxy`, `python-dotenv`
